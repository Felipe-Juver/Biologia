# 🌿 Bioma Cerrado — Trabalho de Biologia

Este projeto consiste em um **site educativo desenvolvido como trabalho de Biologia sobre o Cerrado brasileiro**. O objetivo é apresentar informações sobre esse importante bioma, sua biodiversidade, suas características naturais, as ameaças ambientais que enfrenta e a importância de sua preservação.

## 📚 Sobre o projeto

O site reúne conteúdos organizados em diferentes páginas para facilitar a navegação e a aprendizagem sobre o Cerrado. A proposta é utilizar a web como ferramenta de pesquisa e conscientização ambiental.

## 🗂️ Páginas do site

- **Início (`index.html`):** apresentação do site e introdução ao tema.
- **Sobre o Cerrado (`sobre.html`):** informações gerais sobre o bioma.
- **O Bioma (`bioma.html`):** características naturais, como fauna, vegetação, clima, solo e hidrografia.
- **Impactos Ambientais (`impactos.html`):** exemplos de ameaças ao Cerrado, como desmatamento, queimadas, poluição e degradação do solo.
- **Conservação (`conservacao.html`):** conteúdo sobre a importância da preservação do bioma.
- **COP30 (`cop30.html`):** relação entre o tema ambiental, a preservação do Cerrado e as discussões climáticas.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura das páginas.
- **CSS3** — estilos e apresentação visual.
- **Bootstrap** — recursos de layout e componentes visuais utilizados no site.
- **Imagens** — apoio visual para ilustrar o bioma, seus animais e os impactos ambientais.

## 🚀 Como visualizar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra-o em um navegador para visualizar o site.

> Para manter todas as imagens funcionando, preserve a pasta `img` e os caminhos relativos dos arquivos ao mover ou copiar o projeto.

## 🌎 Objetivo educacional

O trabalho busca apresentar o Cerrado, destacar sua importância para a biodiversidade e para os recursos hídricos e incentivar a reflexão sobre os impactos das atividades humanas e a necessidade de conservação ambiental.

## 🎓 Contexto acadêmico

Projeto desenvolvido para fins **educacionais**, como atividade de Biologia. O conteúdo e o site têm como finalidade apoiar o estudo e a conscientização sobre o Cerrado brasileiro.
